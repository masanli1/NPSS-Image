# NPSS-Image

作者：[masanli1](https://github.com/masanli1) · 仓库：[NPSS-Image](https://github.com/masanli1/NPSS-Image)

[English](README.md)

> **块 DCT 收缩 + 跨相位结构置信度。**
> 单文件，只依赖 numpy + Pillow，无训练、无 GPU、无模型权重。

## 算法

1. **只保留稳定的系数**：8×8 分块 DCT，`|C| > k0·σ` 才保留，DC 永远保留；
   在 16（最多 64）个分块相位上重复并平均 —— cycle spinning 消掉块边界。
2. **结构稳定的地方放宽阈值**：把每个相位的保留/丢弃判决反投影回图像空间，
   得到结构置信度图 `rho`；阈值再乘上 `(1 - λ·rho)`。
   一个区域在所有相位下都被判为结构，就允许更多弱系数通过。

`rho` 是本算法的关键，细节见下面「为什么必须清掉 DC」。

## 实测

`python3 benchmark.py` 可复现（384×384 彩色，固定种子，AWGN，σ 为 0–255 标度）。

| λ（增强强度） | σ=15 PSNR | σ=25 PSNR |
|---|---|---|
| 0.0（原版） | 29.12 | 26.21 |
| 0.3 | 29.46（+0.34） | 26.54（+0.32） |
| **0.5（默认）** | **29.59（+0.47）** | **26.66（+0.45）** |
| 0.7 | 29.62（+0.50） | 26.68（+0.46） |
| 0.9 | 29.53（+0.41） | 26.55（+0.34） |

σ=15、λ=0.5 时逐图：

| 纹理 | 原版 | 增强后 | 提升 |
|---|---|---|---|
| 草地（高频） | 26.63 / 0.771 | 27.28 / 0.832 | +0.65 dB，SSIM +0.061 |
| 织物（交叉网格） | 27.36 / 0.939 | 27.61 / 0.956 | +0.25 dB，SSIM +0.017 |
| 分形 1/f | 26.42 / 0.739 | 27.11 / 0.824 | +0.69 dB，SSIM +0.085 |
| 砖墙（周期） | 36.07 / 0.959 | 36.35 / 0.959 | +0.28 dB，SSIM ±0.000 |

平滑照片（Kodak `kodim23`）提升较小但仍是正的：σ=15 时 34.53 → 34.66 dB，SSIM 不降。

## 用法

```python
import numpy as np
from PIL import Image
import npss_image as M

img = np.asarray(Image.open("photo.jpg").convert("RGB"), np.float32) / 255.0
out, _ = M.denoise_structural(img, sigma=None, k0=3.0, blocks=(4, 8, 16), lam=0.5)
Image.fromarray((np.clip(out, 0, 1) * 255 + 0.5).astype(np.uint8)).save("denoised.png")
```

命令行：

```bash
python3 demo.py photo.jpg                              # 自动估噪 + 最佳参数
python3 demo.py photo.jpg --sigma 25 --ref clean.png   # 附带 PSNR / SSIM
python3 benchmark.py --sigma 15 25 --lam 0 0.5 0.9
```

API 里 `sigma` 用 0–1 标度，命令行用 0–255 标度。`sigma=None` 表示自动估计。

## 为什么必须清掉 DC

置信度图是把「保留掩码」反变换回图像空间得到的。DC 系数**永远**被保留，
如果把它算进掩码，它会主导反变换，整张图被压成近似常数。

实测结构区（梯度前 10%）与平坦区（梯度后 40%）的分离度：

| 掩码 | 结构区 | 平坦区 | 分离度 |
|---|---|---|---|
| 含 DC | 0.491 | 0.496 | **0.00**（完全无效） |
| **清 DC** | **0.415** | **0.072** | **0.34** |

一行 `g[..., 0, 0] = 0` 决定了这张图是有用信号还是噪声。

## 它不是什么

- **不是 BM3D 的对手**。它只看块内信息；BM3D 还会在整幅图里找相似块、把它们的证据
  汇总后再判决，这在纹理密集的图上有 2–4 dB 的价值，本算法没有去做。
  平滑图、中等噪声下差距不到 1 dB。要补这个差距需要非局部冗余，而不是更聪明的阈值。
- **不是学习型方法**。没有训练集、没有权重、不需要 GPU。
- **周期纹理是它的软肋**。砖墙/棋盘这类图案会在固定块网格上混叠，置信度图趋于平坦，
  增强几乎无效（SSIM 可能掉 0.002）。

## 说明

- 64 相位 cycle spinning 等于对图像做 4 遍完整扫描；600×400 彩色约 2 秒（单线程）。
  追求速度可以用 `blocks=(8,)` + `lam=0`，快约 4 倍。
- 模块内把 BLAS 限制为单线程：小矩阵批次下单线程反而更快。
